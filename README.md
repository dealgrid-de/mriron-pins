# mriron-pins

Bild-Ablage und Upload-Plan für die Pinterest-Pins von **Mr. Iron Unterrichtsmaterial** (de.pinterest.com/mrironeduki).

- `pins/` – 294 Pin-Bilder (1000 × 1500), Dateiname = laufende Nummer im Plan
- `plan.json` – alle Pins mit Datum, Uhrzeit (Berlin), Pinnwand, Titel, Beschreibung, Link
- `csv/` – Pinterest-Bulk-Upload-Dateien (Einstellungen → Inhalte importieren → CSV), Zeiten in UTC

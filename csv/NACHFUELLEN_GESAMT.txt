Claude in Chrome: neuen Tab, https://de.pinterest.com/MrIroneduki/scheduled-pins/ öffnen, 5 s warten, per javascript_tool 40× um 1200 px scrollen (600 ms Pause), aus jedem [data-test-id="pin"] bzw. [data-grid-item="true"] (innerText, Leerraum zusammengefasst) per /(\d+)\.(\d+)\.,? (\d\d):(\d\d)/ Tag, Monat, Stunde, Minute lesen; Jahr 2026 bei Monat ≥ 10, sonst 2027; Anzeige ist MEZ → UTC = Stunde−1 (ab 28.3.2027 −2). Ergebnis als kommagetrennte Liste 'YYYY-MM-DDTHH:MM' zurückgeben (nur die Liste, nicht truncaten: ggf. in zwei Hälften), dazu die Zahl aus „NN Pins ‧“.
2. cd /home/claude/mriron-pins && git pull -q && python3 csv/refill.py '<Liste>' <Anzahl>. Bei batch 0: fertig.
3. https://de.pinterest.com/settings/bulk-create-pins öffnen. Inhalt von csv/batch.json (JSON-String) per javascript_tool als String c einsetzen: new File([c],'pins.csv',{type:'text/csv'}) per DataTransfer in #csv-input, change-Event auslösen, 6 s warten, „Hochladen erfolgreich!“ prüfen, Button „Alles klar!“ klicken.
